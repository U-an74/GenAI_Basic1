# GenAI_Basic1 : LLM 기반 업무 자동화

## 과제 목표
아래 3가지 산출물을 포함하는 **업무 자동화 프롬프트 패키지** 제작

### 📄 LLM 모델 비교/선정 
동일한 업무 과업 프롬프트(테스트 질문/케이스 포함)를 3종 이상의 모델에 입력하고, 모델별 결과 비교표와 최종 선정 결론(근거 포함)을 정리하였다. 

→ [LLM 모델 비교/선정 보고서](./LLM_Selection_Report.md)
( 📌참고: [상세 평가 결과표](./appendix/%5B부록%5D%20LLM별%20상세%20평가%20결과표.md) )

### 📄 시스템 설계
타겟 사용자/업무 문제/페르소나/시스템&유저 프롬프트/Few-shot 예시/검증 전략을 포함하며, 프롬프트 버전(v1→v2) 개선 이력과 최종 프롬프트(전문)를 정리하였다. 
→ [시스템 설계 문서](./system_design_doc.md)

### 🗨️ 실행 로그 기록
선택한 업무 과업 시나리오로 10턴 이상 실제 대화를 수행한 전문과, 문제 발생 지점(환각/문맥 끊김 등) 및 수정 결과 요약을 담아 로그 문서를 작성하였다.  
→ [실행 로그](./execution_log.md)
